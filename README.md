# Reservas Clínica — Demo

Sistema web de reservas para una clínica, desarrollado como proyecto de demostración para gestionar citas de forma sencilla.

**Ver demo:** https://jeremias123r.github.io/Reserva-clinicas/

## Qué hace

- Registro de reservas mediante formulario.
- Registro de nombre y teléfono del paciente.
- Selección de servicio.
- Selección de médico.
- Horarios disponibles según el servicio seleccionado.
- Bloqueo de fechas anteriores a la fecha actual.
- Validación de los campos del formulario.
- Prevención de reservas duplicadas para el mismo médico, fecha y horario.
- Guardado de reservas mediante `localStorage`.
- Visualización de las reservas registradas.
- Estados automáticos:
  - Pendiente
  - En curso
  - Vencida
  - Atendida
- Actualización automática del estado de las reservas.
- Opción para marcar una reserva como atendida.
- Opción para eliminar reservas.
- Diseño responsive para dispositivos móviles y computadoras.

## Tecnologías

HTML, CSS y JavaScript · LocalStorage · GitHub Pages

## Datos y privacidad

El proyecto es una demostración ficticia.

No utiliza datos reales de pacientes ni está destinado a gestionar información médica real.

Los datos introducidos en el demo se almacenan únicamente de forma local mediante `localStorage`.
